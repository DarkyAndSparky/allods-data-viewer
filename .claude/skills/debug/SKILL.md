---
name: debug
description: Diagnose the root cause of a bug, reproduce it, fix it and verify.
---
Capture the exact symptom, file and offset. Reproduce with a synthetic input before editing. Form falsifiable hypotheses, trace to the root cause, add a regression test, make the minimal fix, run focused then full checks, report evidence and remaining uncertainty. Never ask for or commit game files; ask the maintainer for a hex dump of the relevant bytes instead.
