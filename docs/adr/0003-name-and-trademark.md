# ADR-0003: Project name "Allods Data Viewer"
Status: Accepted (trademark and logo rights open, see GAPS G-14)
Date: 2026-11-09
Owner: maintainer

## Context
The maintainer chose the name. "Allods" is a game trademark; the logo and icon were supplied by the maintainer.
## Decision
Use the name, with a legal notice in README: unofficial fan tool, no affiliation, no game assets distributed.
## Alternatives considered
A neutral name without the trademark.
## Consequences
A rights holder may ask for a rename; keep the name in few places (docs, About, package names).
## Security, license and maintenance impact
The game font is never redistributed; the UI falls back to a system font.
## Revisit when
A takedown request arrives or the logo rights are clarified.
