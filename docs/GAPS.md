# Список упущений (рабочий документ, русский)

Состояние на 2026-11-09, версия проекта 0.0.1 (веха M0). Составлен по сверке проекта с правилами пакета «AI Agent Engineering Pack v2.0» и с документами безопасности das-forge-core. Формат как в `audit-findings.md` ядра.

## Как читать

- **Проверка**: `✔` проверено мной сейчас (файл прочитан или команда запущена в песочнице Linux); `○` по рассуждению или по памяти, не проверено.
- **Серьёзность**: high, medium, low.
- **Статус**: «закрыто» значит, что исправление лежит в этой поставке (v4), но его ещё не собирали на вашей машине и в GitHub Actions.
- Что запускалось в песочнице сегодня: `cargo fmt --check`, `cargo clippy -D warnings`, `cargo test` (7 тестов Rust), `npm run typecheck`, `npm test` (11 тестов), `npm run build`, `node --test` (41 тест скриптов). Всё прошло. Windows и GitHub Actions не запускались.

## Подробности

**G-04.** До сегодняшнего прогона «проверено» означало «собралось у меня в контейнере». Сегодня прогнан полный набор (см. выше). Это Linux, Rust 1.97.0. На Windows нужно выполнить `cargo test --workspace` и `cd web && npm ci && npm test`, прислать вывод.

**G-05.** Добавлены `deny.toml` (разрешённые лицензии: MIT, Apache-2.0, BSD, ISC, Zlib, Unicode-3.0, MPL-2.0, CC0; запрещены неизвестные реестры и git-источники) и `.github/workflows/security.yml` (hygiene, `cargo deny`, `cargo audit`, `npm audit`, `npm audit signatures`, еженедельно). `cargo deny check` (0.20.2) прошёл: advisories, bans, licenses, sources ok; для этого в корневом `Cargo.toml` у `adv-core` указана версия. `cargo audit` и `npm audit` в песочнице не запускались. Версии инструментов проверены по crates.io: cargo-deny 0.20.2 (2026-07-09), cargo-audit 0.22.2 (2026-06-05). Если какая-то зависимость из плана не пройдёт список лицензий, решать вручную (symphonia MPL-2.0 в списке).

**G-06.** `rust-toolchain.toml` закрепляет 1.97.0 (rustc 2026-07-07). При первом запуске rustup скачает его сам. В песочнице без сети файл мешает, поэтому проверки шли с `RUSTUP_TOOLCHAIN=stable`.

**G-07.** `actions/checkout@v4`, `actions/setup-node@v4`, `Swatinem/rust-cache@v2`, `dtolnay/rust-toolchain@stable` взяты по памяти. Dependabot (уже включён для github-actions) предложит обновления; даты проверьте на странице релизов. Закрепление по SHA не сделано.

**G-12.** Нужно решить числа: максимум распакованного размера записи, коэффициент сжатия, глубина слоёв zlib, число записей в паке, длина пути, размер .loc целиком в памяти (наш максимум 71 577 688 байт). План fuzz: `cargo-fuzz` 0.13.2 (2026-06-09), цель на каждый читатель, когда он появится.

**G-14.** Вопрос к вам: логотип и иконка нарисованы вами или взяты у издателя? Если взяты, публиковать их в MIT-репозитории нельзя без разрешения. Шрифт Allods.ttf в репозиторий не кладётся и в установщик не входит.

**G-18.** Образцы, которые нужны (имена и размеры, не содержимое для репозитория): список Packs, маленькие `.fsb`/`.bsb`, текстура `.bin` с записью из БД, `pack.bin` и версия клиента, `.xdb`, модель с текстурами, один `.ogv`.
