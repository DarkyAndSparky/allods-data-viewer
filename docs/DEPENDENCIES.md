# Зависимости

Проверенные по реестрам даты релизов и лицензии, решения по каждой библиотеке.

Дата и источник проверки: 2026-11-09, API реестров crates.io и npmjs.com (даты публикации последней стабильной версии и лицензия). Из 29 проверенных Rust-пакетов и 8 npm-пакетов правило «релиз текущего года» не прошли шесть Rust-пакетов (ниже, чем их заменяем). Версии могут устареть: перед добавлением в манифест проверять заново.

## Правило и процесс

1. Прямая зависимость и инструмент разработки берутся только с релизом 2026 года. Дата — это дата публикации последней стабильной версии в реестре, не запись из памяти.
2. Перед добавлением в `Cargo.toml` или `package.json` проверяем два факта: дата релиза и лицензия (совместима с MIT).
3. Переходные зависимости — последние доступные, правило к ним не применяется.
4. Если нужный пакет не выпускался в 2026 году, мы его не берём без решения владельца, а пишем простую часть сами (WAV, CSV, обход каталогов) или ищем замену.
5. Версии пакетов до 1.0 (`three`, `tauri-plugin-*`) закрепляем точной версией: у них ломающие изменения между минорными выпусками.
6. Dependabot открывает еженедельные запросы на обновление для cargo, npm и GitHub Actions. Версии GitHub Actions в CI пока не сверялись по реестру (упущение G-07).
7. Правило проверяется `cargo deny` (`deny.toml`) по лицензиям и источникам; дату релиза пока проверяет человек.
