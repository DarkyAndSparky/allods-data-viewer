# Решения и вопросы

Журнал принятых решений (полные ADR: `docs/adr/`) и открытые вопросы к владельцу проекта. Эта вкладка в онлайн-документе была пустой; здесь она заполнена впервые.

## 1. Принятые решения

| ID | Решение | Основание | Где записано |
| --- | --- | --- | --- |
| D-001 | Лицензия MIT; код чужих проектов без лицензии, AGPL и GPL не копируем (clean-room); форматы описываем своими словами | совместимость, чистота происхождения | ADR-0001, `docs/REFERENCES.md` |
| D-002 | Зависимости и инструменты только с релизом текущего календарного года; даты проверяем по реестру | требование владельца | ADR-0002, `docs/DEPENDENCIES.md` |
| D-003 | Имя «Allods Data Viewer», проект неофициальный (fan project); «Allods» — чужая торговая марка | выбор владельца, снижение риска | ADR-0003 |
| D-004 | Ядро на Rust, CLI `adv`, интерфейс TypeScript + Vite + Three.js, оболочка Tauri 2 позже; Windows и Linux | выбор владельца | `docs/ARCHITECTURE.md` |
| D-005 | Тулчейн закреплён: Rust 1.99, edition 2024 | на машине владельца установлен 1.99 | `rust-toolchain.toml` |
| D-006 | Игровых данных в репозитории нет: ни паков, ни текстов, ни шрифта; образцы только вне репозитория (`ADV_SAMPLES`) | права и лицензия | `scripts/check-repo.mjs`, CLAUDE.md |
| D-007 | Видео у нас Ogg (`.ogv`), работаем с ним как с Ogg; отдельной задачи «импорт видео» нет | уточнение владельца | `docs/FORMATS-PLAN.md`, раздел 9 |
| D-008 | Декодирование Vorbis через `symphonia` (кандидат, решим после образцов); MP3 только через внешний `lame` или `ffmpeg` | LAME под LGPL, не вшиваем | `docs/DEPENDENCIES.md` |
| D-009 | Правила разработки с ИИ: цикл «изучить, план, выполнить, проверить, отчёт», классы риска R0–R4, метки VERIFIED / NOT VERIFIED; охранник команд на Node с тестами | пакет коллеги v2.0, переработан | `docs/engineering/WORKFLOW.md`, `scripts/guard.mjs` |
| D-010 | Безопасность: `SECURITY.md`, `cargo deny`, `cargo audit`, `npm audit`, CODEOWNERS, шаблоны PR и issue | взято из das-forge-core | `.github/`, `deny.toml` |
| D-011 | Среда разработки: полноценная IDE (RustRover, Rider, Visual Studio); VS Code не предлагаем | требование владельца | CLAUDE.md |
| D-012 | Владелец сам собирает и тестирует на Windows; всё, что не запускалось, помечается как не проверенное | процесс | CLAUDE.md |
| D-013 | Полный архив репозитория (с `.git`) отдаём при каждой поставке | требование владельца | процесс |

## 3. Статус вех

| Веха | Содержание | Статус |
| --- | --- | --- |
| M0 | каркас репозитория, CI, документы, правила | сделано, на Windows и в GitHub Actions не запускалось |
| M1 | чтение `.pak`, `.loc` v1/v2, `adv info/list/extract/search/loc dump/verify` | не начато (ждём команду «кодим»); `.loc` v2 ждёт образцы |
| M2 | текстуры `.bin` → DDS/PNG | ждёт образцы |
| M3 | звук `.bsb`/`.fsb` → WAV/OGG/MP3 | ждёт образцы |
| M4 | видео `.ogv` | ждёт образец |
| M5 | приложение Tauri, просмотр | не начато |
| M6 | базы ресурсов → JSON/XML | ждёт образцы |
| M7–M9 | модели, материалы, 3D-просмотр | формат неизвестен |
| M10 | упаковка нового `.pak` | не начато |
| M11 | выпуск: установщики, SBOM, контрольные суммы | не начато |
