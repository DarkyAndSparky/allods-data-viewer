# Архивы `.tar`, `.tar.gz`, `.tgz`, `.gz`, `.tar.xz`, `.txz`, `.xz`, `.7z`

Статус: `verified` на синтетических архивах (тесты в `crates/core/src/archive.rs` и `crates/session`); реальных архивов пользователя в образцах не было.

Просмотр открывает эти файлы как папки (как `.zip` и `.pak`). Код: `adv_core::archive::Archive`; в `adv` (командная строка) они пока не поддерживаются, только в приложении.

**TAR.** Заголовки 512 байт; контрольная сумма проверяется. Размер: восьмеричный или base-256 (старший бит), с проверкой переполнения. Понимаются обычные файлы, длинные имена GNU (`L`), расширенные заголовки pax (`x`: `path`, `size`) и поле `prefix` в ustar. Каталоги, ссылки и прочие типы пропускаются с причиной. Пути идут через `VPath` (запрещены `..` и абсолютные), повторы, слишком большие записи и данные за концом файла пропускаются с причиной. Повреждённый заголовок после первого обрывает список: уже найденные записи остаются доступны, причина сохраняется. Первый повреждённый заголовок — ошибка «это не tar». Данные читаются по требованию.

**GZ / TGZ.** Файл целиком распаковывается в память с потолком `max_inflated_size` и защитой по степени сжатия (`max_ratio`); несколько gzip-блоков подряд читаются как один. Если внутри tar (сигнатура `ustar` и верная сумма), он разбирается как выше. Иначе `.gz` показывается как один файл с именем без `.gz`.

**XZ / TXZ.** Как GZ: распаковка в память (`lzma-rust2`, чистый Rust) с тем же потолком и защитой по степени сжатия, лимит памяти декодера 256 МиБ, несколько потоков подряд читаются как один. Внутри tar разбирается как выше, иначе один файл.

**7Z.** Список берётся из заголовка (`sevenz-rust2`, чистый Rust, без AES/bzip2/ppmd): каталоги и anti-элементы пропускаются, пути через `VPath`, повторы и записи больше `max_inflated_size` пропускаются с причиной, число записей ограничено `max_entries`. Запись распаковывается по требованию с потолком по размеру из заголовка. Монолитный (solid) блок распаковывается с начала до нужного файла, поэтому последний файл большого solid-блока читается так же долго, как весь блок. Работают методы, которые есть в `lzma-rust2`/`sevenz-rust2` без отключённых возможностей: LZMA, LZMA2, фильтры, copy; зашифрованные и bzip2/ppmd/zstd/brotli архивы дадут ошибку при чтении записи. Проверено на синтетических архивах, на реальных `.7z` не проверялось.

Не поддерживаются: `.tar.bz2` (единственный крейт `bzip2` 0.6.1 вышел в 2025 году, прямой `libbz2-rs-sys` требует `unsafe`; решение владельца), `.rar` (единственный крейт `unrar` оборачивает исходники UnRAR с несвободной лицензией; свободного читателя на Rust нет), tar без `ustar`-сигнатуры внутри `.gz`/`.xz` (будет показан как один файл).
