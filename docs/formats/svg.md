# SVG: безопасный просмотр

Статус: `verified` (поведение санитайзера проверено тестами; показ в браузере и `adv-desktop` на Windows не проверены).

Игровых `.svg` в образцах нет; файл может прийти из мода или от пользователя, поэтому он считается недоверенным. Реализация: `crates/core/src/svg.rs`.

Порядок: файл читается небольшим XML-разборщиком; затем **записывается новый документ** только из разрешённых элементов, атрибутов и значений (allow-list). Всё остальное вырезается и считается; пользователю показывается, что удалено. Файл, который не разбирается (незакрытые теги, DOCTYPE с подмножеством или сущностями, корень не `svg`, вложенность больше 128, больше 200000 элементов, больше 4 МиБ), не показывается картинкой, а открывается как текст.

Разрешено: фигуры, текст, группы, `defs`, `symbol`, `use` (только `#фрагмент`), градиенты, `pattern`, `clipPath`, `mask`, `marker`, `filter` и безопасные примитивы (`feGaussianBlur`, `feOffset`, `feColorMatrix` и др.), `image` только с `data:image/png|jpeg|gif|webp;base64`. Запрещено: `script`, `foreignObject`, `animate`/`set`, `style`, `a`, `iframe`, обработчики `on*`, внешние ссылки, `url()` не на `#фрагмент`, `javascript:`, `expression(`, `@import`.

Второй рубеж: чистая копия рисуется через `<img>` (blob `image/svg+xml`); в таком режиме браузер не выполняет скрипты и не грузит внешние ресурсы.
