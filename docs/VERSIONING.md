# Нумерация версий

Формат `0.1.X`. Решение владельца (2026-11-10): пока держимся на третьей цифре, вторую не меняем.

- Каждая новая поставка (архив, выпуск) увеличивает только **третью цифру**: `0.1.0`, `0.1.1`, `0.1.2` и так далее.
- Вторая цифра (`0.2.0`) меняется только по явному решению владельца. Первая (`1.0.0`) тоже.
- Менять версию только командой `node scripts/version.mjs set X.Y.Z` (проверка: `node scripts/version.mjs check`, она же в CI). Скрипт трогает только свои пакеты `adv-*` в `Cargo.lock`, чужие крейты с таким же номером не задеваются (замена `sed` по всему файлу однажды испортила `tracing-core`). Мест несколько: `Cargo.toml` (пакет и зависимость `adv-core`), `Cargo.lock` (`adv-core`, `adv-cli`), `web/package.json` и `web/package-lock.json`. Меняются вместе; `cargo test` и `npm run build` показывают рассогласование.
- Архив называется `allods-data-viewer-<версия>.zip`.
- Версия формата JSON-вывода CLI (`schema`) и версия проекта независимы.
- История: 0.0.1 (веха M0, v1–v7 до этой нумерации), 0.1.0 (первая поставка с новой нумерацией, Node 26), 0.1.1 (M1a и M1b: чтение `.pak`, `.loc`, команды `info/list/extract/loc dump/search`; CodeQL, gitleaks, Actions v7), 0.1.2 (`adv verify`, `--json` у `info` и `list`), 0.1.3 (текстуры: `adv tex info/convert`, DXT1/3/5 → PNG/DDS), 0.1.4 (правки по итогам первой сборки на Windows: clippy 1.99, `check-repo` без `.git`), 0.1.5 (звук: `adv audio list/export`), 0.1.6 (текстуры: размер и формат из `.xdb`, `--crop`), 0.1.7 (база ресурсов: `adv db info/list/packs`), 0.1.8 (`adv db list` показывает тип объекта; закрытый конвейер не даёт паники), 0.1.9 (`adv db textures`: тип, размер и число mip объектов Texture), 0.1.10 (`tex convert --db <pack.bin> [--db-id]`: размер и формат из базы), 0.1.11 (`tex convert` угадывает размер и формат без `.xdb`: `--index`, `--tdb`; `adv geom info/obj`), 0.1.12 (`adv db find`: поиск баз ресурсов внутри паков), 0.1.13 (`adv audio export` со встроенным декодером Vorbis). 0.1.45 (чтение баз ресурсов 32-бит `db32` для Cloud Pirates и клиента 10.0, размер текстур из базы в просмотре, форматы RGB565/RGBA4444/BGRA8888/L8, склейка `.hi.bin`; в документацию добавлена спецификация аудита и модов), 0.1.46 (`game.version` как список в просмотре, текст в Windows-1251), 0.1.47 (выбор размера вершины по конечным координатам: открываются `Ship4_Hull`, `ElfFemale`, `HadaganFemale`), 0.1.48 (`game.version` ищется в папке, в её `Profiles`, в родителе и его `Profiles`), 0.1.49 (стрелки в дереве, сворачиваемая строка состояния, компактное дерево), 0.1.50 (Tab-автодополнение пути, сброс вида картинки), 0.1.51 (Esc снимает выделение файла), 0.1.52 (поиск только в выбранной папке), 0.1.53 (экспорт текстов и `.loc` в txt, html, xml), 0.1.54 (TGA и `.cur`), 0.1.55 (`game.version` ищется на два уровня выше открытой папки), 0.1.56 (фильтр папок Mods и addons), 0.1.57 (просмотр папки как в проводнике: крошки, «вверх»), 0.1.58 (`.zip` как архив).
