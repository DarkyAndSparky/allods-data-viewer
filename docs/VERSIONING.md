# Нумерация версий

Формат `0.1.X`. Решение владельца (2026-11-10): пока держимся на третьей цифре, вторую не меняем.

- Каждая новая поставка (архив, выпуск) увеличивает только **третью цифру**: `0.1.0`, `0.1.1`, `0.1.2` и так далее.
- Вторая цифра (`0.2.0`) меняется только по явному решению владельца. Первая (`1.0.0`) тоже.
- Версия прописана в четырёх местах: `Cargo.toml` (пакет и зависимость `adv-core`), `Cargo.lock` (`adv-core`, `adv-cli`), `web/package.json` и `web/package-lock.json`. Меняются вместе; `cargo test` и `npm run build` показывают рассогласование.
- Архив называется `allods-data-viewer-<версия>.zip`.
- Версия формата JSON-вывода CLI (`schema`) и версия проекта независимы.
- История: 0.0.1 (веха M0, v1–v7 до этой нумерации), 0.1.0 (первая поставка с новой нумерацией, Node 26), 0.1.1 (M1a и M1b: чтение `.pak`, `.loc`, команды `info/list/extract/loc dump/search`; CodeQL, gitleaks, Actions v7), 0.1.2 (`adv verify`, `--json` у `info` и `list`), 0.1.3 (текстуры: `adv tex info/convert`, DXT1/3/5 → PNG/DDS).
