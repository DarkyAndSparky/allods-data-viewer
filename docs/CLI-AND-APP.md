# CLI и приложение

Полный справочник команд `adv`, команд обмена между интерфейсом и ядром, экранов и состояний.

Реализовано в 0.1.1: `adv info`, `list` (`--filter` со звёздочкой вместо `--glob`, `--long`, `--sort`), `extract` (`-o`, `--filter`, `--raw`, `--overwrite`, `--flat`), `loc dump` (`--format csv|tsv|json`, `--entry`, `-o`, `--bom`), `search` (`--keys`, `--limit`; файл или папка с `.loc` и `.pak`). Коды выхода: 0, 1, 2 (часть пропущена или файлы уже были). Остальное ниже — предложение. С 0.1.3 есть `tex info <файл>` и `tex convert <файл> --size ШxВ --dxt 1|3|5 [--format png|dds] [--mip K] -o <файл>` (рядом лежащий `.hi.bin` подхватывается сам; `--size` и `--dxt` обязательны, пока нет базы). С 0.1.2 есть `verify <pak|папка>` (код выхода 1 при проблемах) и `--json` у `info` и `list`. Не сделано: `--glob`, `--jobs`, `--regex`, `--ignore-case` (поиск всегда без учёта регистра). Список команд согласован с `docs/ROADMAP-DETAILED.md`.

## 1. Общие правила CLI

| Правило | Значение |
| --- | --- |
| Глобальные флаги | `--json` (машинный вывод в stdout), `--quiet` (без прогресса), `--no-color`, `--lang ru|en` |
| stdout и stderr | данные в stdout, прогресс, предупреждения и ошибки в stderr; при `--json` stdout содержит ровно один JSON-документ или по одной строке JSON на запись (`--json-lines`, для длинных списков) |
| Коды выхода | `0` успех; `1` ошибка (файл, формат, предел); `2` частичный успех (часть элементов пропущена); `64` неверные аргументы (как у clap); `130` отменено |
| Пути | принимаются в форме для текущей ОС; пути внутри паков всегда с `/` |
| Перезапись | `extract` не перезаписывает файлы без `--overwrite`; запись идёт во временный файл и только потом переименовывается |
| Не меняет игру | CLI никогда не пишет внутрь исходных `.pak`; вывод всегда в явно указанную папку `-o` |
| Схемы JSON | в каждом JSON-ответе поле `schema` (число); поля только добавляются в рамках одного номера |
| Отмена | `Ctrl+C` прерывает операцию, дописанные файлы целы, недописанный удаляется |
| Сеть | CLI и приложение не делают сетевых запросов вообще |

Форма ошибки в `--json`: `{ "schema": 1, "error": { "kind": "Format", "message": "...", "file": "...", "offset": 1234 } }`. Поля `file` и `offset` необязательны.

## 2. Команды по этапам

### M1: архивы и локализация

| Команда | Аргументы и флаги | Результат |
| --- | --- | --- |
| `adv info <файл>` | файл: `.pak`, `.loc`, или другой известный | формат (`Kind`), размер, слой zlib, для `.loc` раскладка и число элементов, для `.pak` число записей |
| `adv list <pak \| папка>` | `--glob <шаблон>` (многократно), `--sort name\|size`, `--long` | по строке на запись: путь; с `--long` ещё размер, сжатый размер, CRC32, метод, имя пака |
| `adv extract <источник> <путь \| шаблон> -o <папка>` | `--raw` (не снимать слой zlib), `--overwrite`, `--flat` (без подпапок), `--jobs N` | файлы на диске; итог: сколько извлечено, пропущено, ошибок; коллизии имён перечислены |
| `adv search <папка> <текст>` | `--keys`, `--text`, `--regex`, `--ignore-case`, `--limit N` | найденные пары (файл, ключ, фрагмент текста) |
| `adv loc dump <файл>` | `--format csv\|json\|tsv`, `--bom`, `-o <файл>` | все записи `.loc` (ключ, текст) |
| `adv verify <pak \| папка>` | `--jobs N` | проверяет CRC32 всех записей и выводит итог (**предложение**, из идеи цепочки хешей аудита ядра) |

Пример ответа `adv list --json` (по строке на запись при `--json-lines`):

```json
{ "schema": 1, "pack": "Texts.pak", "path": "Bin/pack.rus.loc", "size": 47185920, "packed": 12345678, "crc32": "1A2B3C4D", "method": "deflate" }
```

Значения в примере выдуманы для показа формы, реальных данных они не изображают.

### M2–M4: текстуры, звук, видео

| Команда | Аргументы и флаги | Результат |
| --- | --- | --- |
| `adv tex convert <файл>` | `--format png\|dds`, `--size ШxВ` (до появления базы), `--dxt 1\|3\|5`, `--mips N`, `--mip K` (какой уровень в PNG) | картинка в указанном формате |
| `adv audio list <банк>` | `--json` | потоки: номер, имя, частота, каналы, длительность |
| `adv audio export <банк \| папка> -o <папка>` | `--format wav\|ogg\|mp3`, `--jobs N`, `--lame <путь>` | массовый экспорт; `mp3` только если найден `lame`/`ffmpeg`, иначе понятная ошибка |
| `adv video info <файл>` | | контейнер Ogg, потоки, кодеки, длительность, размер кадра (пока `draft`) |
| `adv video extract <pak> -o <папка>` | `--glob` | извлекает `.ogv` |

Если формат ещё `unknown` или `draft`, команда не выдумывает результат: она пишет предупреждение «формат не подтверждён» или отказывается.

### M6–M10: базы, модели, упаковка

| Команда | Аргументы и флаги | Результат |
| --- | --- | --- |
| `adv db info <база>` | | версия (хеш), V1 или V2, x86 или x64, число ресурсов, список Packs |
| `adv db list <база>` | `--type tga\|bin\|ogv\|...`, `--glob` | ресурсы с именами и ссылками на паки |
| `adv db export <база> -o <папка>` | `--format json\|xml` | таблицы в файлы (только для версий с известными структурами) |
| `adv model export <модель>` | `--format gltf\|glb`, `--with-textures` | файл glTF и текстуры PNG (пока формат `unknown`) |
| `adv pack <папка> -o <новый.pak>` | `--store\|--deflate`, `--level N`, `--manifest` | собирает **новый** `.pak` (ZIP), никогда не правит существующий; отказывается писать в папку клиента игры без `--i-know` |

## 3. Приложение (Tauri): команды между интерфейсом и ядром

Интерфейс (TypeScript) ничего не читает с диска сам. Он вызывает команды Rust. Каждая команда принимает строгую схему аргументов и валидируется на стороне Rust. Доступ к папкам получается только через диалог выбора файла от пользователя (см. `docs/SECURITY-AND-QUALITY.md`).

| Команда IPC | Вход | Выход |
| --- | --- | --- |
| `open_source` | путь, выбранный в диалоге | идентификатор источника, число паков и записей |
| `list_entries` | ид источника, фильтр, страница | страница записей (виртуальный список, не все сразу) |
| `preview` | ид источника, путь | данные предпросмотра по типу: текст, картинка RGBA, дорожка PCM, целый файл для видео, массивы вершин для модели |
| `search` | ид источника, запрос | результаты потоком (события) |
| `export` | список путей, формат, папка из диалога | ид задачи; прогресс событиями |
| `cancel` | ид задачи | признак отмены выставлен |
| `settings_get`, `settings_set` | ключи и значения | настройки (язык, папка клиента, путь к `lame`/`ffmpeg`) |

Тяжёлые данные (картинки, звук, вершины) передаются бинарным ответом, не JSON-строкой. Списки больше 1000 записей постраничные. Недопустимо: читать весь 71-мегабайтный `.loc` в интерфейс.

## 4. Экраны и состояния

Макет интерфейса описан в `docs/ROADMAP-DETAILED.md`. Детали состояний:

| Экран | Состояния |
| --- | --- |
| Старт | пусто («выберите папку клиента»), загрузка с прогрессом, ошибка (папка не похожа на клиент) |
| Дерево файлов | пусто, фильтр без результатов, список на тысячи записей (виртуализация) |
| Предпросмотр | загрузка, готово, «формат не подтверждён» (`draft`/`unknown`), ошибка разбора с деталями для багрепорта, нет декодера |
| Экспорт | выбор формата и папки, шаблон имён, прогресс, отмена, итог с ошибками |
| Настройки | язык, папка клиента, путь к внешним программам |
| О проекте | уже есть (M0): версия, лицензия, юридическое примечание |

## 5. Горячие клавиши (предложение)

| Клавиши | Действие |
| --- | --- |
| `Ctrl+O` | открыть папку клиента или `.pak` |
| `Ctrl+F` | поиск по именам; `Ctrl+Shift+F` поиск по текстам |
| `Ctrl+E` | экспорт выделенного |
| `↑` `↓` | движение по списку |
| `Space` | воспроизведение / пауза звука и видео |
| `Esc` | закрыть диалог, отменить экспорт |
| `F1` | окно «О проекте» |

## 6. Строки интерфейса (i18n)

Все тексты проходят через `web/src/i18n.ts` (языки `ru` и `en`, язык по умолчанию определяется по языку системы). Ключи делаются плоскими со смысловыми префиксами: `app.*`, `menu.*`, `list.*`, `preview.*`, `export.*`, `error.*`, `about.*`. Тест проверяет, что у каждого ключа есть оба перевода. Игровые тексты (из `.loc`) переводу не подлежат и показываются как есть.

## 7. Открытые вопросы по этой части

- Работаем ли с `adv pack` в папку клиента игры или только в свою (предложение: только в свою, замена файлов клиента может нарушить правила игры и апдейтер).
- Нужна ли команда «сравнить две версии клиента» (`adv diff`), в плане будущего она есть.
- Формат CSV: разделитель `,` или `;` (в русском Excel ожидается `;`). Предложение: `--delimiter`, по умолчанию `,`.
